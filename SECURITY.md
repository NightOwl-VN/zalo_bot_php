# Security Policy

> See the full version at [.github/SECURITY.md](.github/SECURITY.md)

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, please report them via GitHub Security Advisory or email the maintainers directly.

You should receive a response within 48 hours. Please include:
- Type of vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix
